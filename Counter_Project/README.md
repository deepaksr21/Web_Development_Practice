# Counter

A simple interactive Counter application built using HTML, CSS, and JavaScript.

## Features

* Increase the counter using the `+` button.
* Decrease the counter using the `-` button.
* Reset the counter using the `Reset` button.
* Increase and decrease the counter using keyboard arrow keys.

  * `Arrow Up` → Increase
  * `Arrow Down` → Decrease
* Press `R` or `r` to reset the counter.
* Counter value is restricted between `0` and `10`.
* Counter color changes according to its current value.
