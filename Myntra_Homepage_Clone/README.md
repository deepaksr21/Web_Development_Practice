**# Myntra UI Clone — HTML \& CSS Practice**



&#x20; A small static recreation of the Myntra website interface, created as a practice exercise while learning HTML and CSS.



&#x20; The main purpose of this exercise was to understand how HTML structure and CSS styling work together to create a webpage layout.



**## About**



&#x20; This is not a complete frontend application. It is a simple UI practice exercise focused mainly on:



&#x20; - HTML page structure

&#x20; - CSS styling

&#x20; - Layout and positioning

&#x20; - Flexbox

&#x20; - Spacing and alignment

&#x20; - Images and assets

&#x20; - Basic navigation and webpage sections



JavaScript and other frontend technologies are not used.



**## Technologies Used**



&#x20; - HTML5

&#x20; - CSS3



**## Purpose**



&#x20; This was built mainly for learning and practice after studying the fundamentals of HTML and CSS.



&#x20; The goal was to take the concepts learned and apply them by recreating the visual structure of an existing website.



**## Note**



&#x20; This is a static practice clone and is not affiliated with or developed by Myntra.



&#x20; It does not include the functionality of the original website, such as user accounts, product management, shopping cart functionality, payments, or other backend     features.
